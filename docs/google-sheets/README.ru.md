# Интеграция с Google Sheets — настройка

[English](README.md) · **Русский**

После каждой обработанной встречи приложение может дописывать в вашу таблицу одну
строку: дата, название встречи, первая строка саммари, длительность, число
участников, количество слов, число задач, тональность, категория и ключевые темы.

Ни OAuth, ни API-ключа не требуется. Вы разворачиваете небольшой скрипт **внутри
своей же таблицы**, а приложение просто отправляет строку на выданный им адрес.
Таблица остаётся вашей — приложение не получает доступ к аккаунту Google.

## Настройка (примерно две минуты)

1. Откройте (или создайте) таблицу, в которую будут собираться встречи.
2. **Расширения → Apps Script**. Удалите всё, что есть в редакторе.
3. Вставьте содержимое файла [`code.gs`](code.gs).
   *(Тот же скрипт доступен в приложении: Настройки → Google Sheets →
   «Скопировать Apps Script».)*
4. **Развернуть → Новое развёртывание → Веб-приложение**:
   - *Запуск от имени:* **Я**
   - *Кому доступен:* **Все**
   При первом развёртывании Google запросит разрешение — это ваш собственный
   скрипт пишет в вашу собственную таблицу.
5. Скопируйте выданный **URL с `/exec`**.
6. **Проверьте, что работает:** откройте этот URL в браузере. Он должен ответить
   `{"ok":true,"service":"meeting-summarizer","ready":true}`. Если вместо этого
   HTML-страница или экран входа — в развёртывании не выставлен доступ «Все».
7. В приложении: **Настройки → Google Sheets**, включите интеграцию и вставьте
   URL с `/exec`.

Строка заголовков пишется автоматически при первом экспорте (жирным, закреплённая).

## Дополнительно: требовать токен

При доступе «Все» единственный секрет — сам URL: кто его знает, тот может
дописывать строки. Чтобы дополнительно требовать токен:

1. В Apps Script: **Настройки проекта → Свойства скрипта → Добавить свойство**,
   имя `SHARED_TOKEN`, значение — любая длинная случайная строка.
2. Укажите то же значение в настройках Google Sheets в приложении.

Запросы без совпадающего токена отклоняются. Если свойство не задавать,
настройка остаётся максимально простой.

## Что делать, если не работает

| Симптом | Причина и решение |
|---|---|
| Приложение пишет «did not return JSON» | Развёртывание не является веб-приложением с доступом «Все», либо взят не тот URL. Разверните заново и скопируйте именно `/exec`. |
| `unauthorized` | В скрипте задан `SHARED_TOKEN`, а в приложении токен не указан или отличается. |
| `no values` | Приложение отправило пустую строку — по встрече не получилось саммари/анализа. |
| `busy, try again` | Две встречи завершились одновременно; строка допишется при следующем экспорте. |
| Две строки заголовков | Возможно только со старой копией скрипта — замените её текущим `code.gs`, он берёт блокировку. |
| Вообще ничего не происходит | Выключена галочка интеграции либо пустое поле URL в настройках. |

## Как изменить состав колонок

Порядок колонок задаётся в `HEADERS` в `desktop/app/backend/gsheets.py`, а сама
строка собирается там же функцией `build_values()`. Скрипт пишет то, что ему
прислали, поэтому достаточно поправить эти два места — `code.gs` трогать не нужно.
